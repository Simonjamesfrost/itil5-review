# SIAM knowledge base (local only)

Source text for `siam-reviewer`. Kiro indexes this folder when the agent starts.

## What to put here

The SIAM guidance from Scopism is a free download:

- **SIAM Body of Knowledge** – the 2025 refresh is on scopism.com (Publications & Frameworks → SIAM Body of Knowledge)
- **SIAM Professional Body of Knowledge, 2nd edition (2019)** and **SIAM Process Guides, 2nd edition (2020)** – the rubric v0.1 was written from these

Save them as `.md` or `.txt` if Kiro won't index PDFs. One file per document is fine.

## Why it isn't in Git

Everything here except this README is gitignored. The 2nd edition documents are licensed CC BY-NC-ND 4.0: you can share unchanged copies for non-commercial use, with credit to Scopism. Downloading them yourself on each machine keeps things simple and avoids any question over company (commercial) use.

The agent works without this folder – it falls back to the rubric and says so in the report.
