# Knowledge base (local only)

Put licensed ITIL (Version 5) reference text here, for example sections of the ITIL Product book you have access to through PeopleCert Plus or a course.

- Save as Markdown or plain text, one file per lifecycle activity works well (`discover.md`, `design.md` …).
- Everything in this folder except this README is gitignored. **Do not commit it** – it is PeopleCert copyright.
- Copy it onto each machine by hand.
- Kiro indexes this folder when the agent starts (`autoUpdate: true`).

The agent works without this folder – it falls back to the rubric and says so in the report.
